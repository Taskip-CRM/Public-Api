# Document Management API

The Document Management API allows you to create and manage documents (and proposals) in your TaskIP workspace. You can list, create, archive and share documents, edit their content blocks, publish them to a public link, and export them as PDF.

## Endpoints Overview

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | [`/api/public-v1/documents`](#get-all-documents) | Get all documents |
| `POST` | [`/api/public-v1/documents`](#create-a-document) | Create a document |
| `GET` | [`/api/public-v1/documents/{uuid}`](#get-a-specific-document) | Get a document with its blocks |
| `DELETE` | [`/api/public-v1/documents/{uuid}`](#delete-a-document) | Archive (delete) a document |
| `POST` | [`/api/public-v1/documents/blocks/store/{uuid}`](#save-document-blocks) | Save the content blocks of a document |
| `POST` | [`/api/public-v1/documents/blocks/rename/{uuid}`](#rename-a-document) | Rename a document |
| `POST` | [`/api/public-v1/documents/blocks/move-to-folder/{uuid}`](#move-a-document-to-a-folder) | Move a document to a folder |
| `POST` | [`/api/public-v1/documents/blocks/share/{uuid}`](#share-a-document-with-a-user) | Share a document with a user (or remove access) |
| `POST` | [`/api/public-v1/documents/blocks/duplicate_document/{uuid}`](#duplicate-a-document) | Duplicate a document |
| `POST` | [`/api/public-v1/documents/download/{uuid}`](#download-document-as-pdf) | Download a document as PDF |
| `POST` | [`/api/public-v1/documents-invite/{uuid}`](#invite-or-revoke-access) | Invite a team member, contact or team (or revoke access) |
| `POST` | [`/api/public-v1/documents-publish/{uuid}`](#publish-or-unpublish-a-document) | Publish or unpublish a document |
| `POST` | [`/api/public-v1/documents-thumbnail/{uuid}`](#update-thumbnail) | Update the thumbnail |
| `POST` | [`/api/public-v1/documents-cover/{uuid}`](#update-cover-photo) | Update the cover photo |
| `POST` | [`/api/public-v1/documents/mention/user`](#mention-a-user) | Notify a user that they were mentioned |

<Callout type="warning" emoji="⚠️">
  **There is no update endpoint.** `PUT /documents/{uuid}` is not available. To change a document use the specific endpoints above (rename, move to folder, save blocks, share, publish, cover).
</Callout>

## Authentication and Common Behavior

Every request must send the secret key header:

```http
X-Secret-Key: your-secret-key-here
Content-Type: application/json
```

- Documents are identified by their **`uuid`** (string), not the numeric `id`.
- The workspace must have the Public API module enabled and plan access, otherwise the request is rejected before reaching the endpoint.
- Requests act as the user linked to the secret key. A document that user cannot access returns an error (see [Error Responses](#error-responses)), and document-level rules (for example, only the owner can share) apply.

### Access Type Values

Used by `access_type` in the share and invite endpoints, and returned in `permissions[].access_type`.

| Value | Meaning |
|-------|---------|
| `1` | Full access |
| `2` | Can edit |
| `3` | View only |
| `4` | Comment only |

### Visibility Values

| Value | Label |
|-------|-------|
| `0` | Private |
| `1` | Public |
| `2` | Team Only |

## Get All Documents

Retrieve a paginated list of documents visible to the user that owns the secret key. Results are ordered newest first (`id` descending).

```http
GET /api/public-v1/documents
```

### Query Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `item` | integer | No | Items per page (default: `10`). Use `0` to return all documents without pagination |
| `page` | integer | No | Page number |
| `search` | string | No | Search by document name |
| `visibility` | integer | No | Filter by visibility. Only `0` and `1` are applied as filters; other values are ignored |
| `status` | integer | No | `1` = only published (shared) documents, `0` = only unpublished documents |

## Create a Document

Create a new document.

```http
POST /api/public-v1/documents
```

### Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | Yes | Document name (max 191 characters) |
| `visibility` | integer | Yes | `0` = Private, `1` = Public, `2` = Team Only |
| `type` | integer | No | `1` = Document (default), `2` = Proposal |
| `is_signable` | boolean | No | Whether the document can be signed (default: `true`) |
| `is_self_signable` | boolean | No | Whether the owner can self-sign (default: `false`) |
| `template_type` | integer | No | `1` = Prebuilt (default), `2` = Custom, `3` = PDF upload |
| `status` | integer | No | `1` = Draft (default), `2` = In Progress |
| `media` | integer | No | ID of an uploaded media file (for example a PDF) to attach |

The service also reads the following optional fields. They are not validated by the request class, so malformed values may produce a server error:

| Field | Type | Description |
|-------|------|-------------|
| `expired_at` | datetime string | Expiry date (default: 15 days from now) |
| `send_in_order` | boolean | Signers must sign in order (default: `false`) |
| `template_id` | string | Template name used to prefill the document blocks |
| `teams` | array | Team IDs to attach to the document |
| `signers` | array | Signer objects. Each uses `email` (required), `order` (required), `name`, `contact_id`, `type`, `status` |

<Callout type="info" emoji="💡">
  `folder_id` is not accepted when creating a document (it is not saved). Use [Move a Document to a Folder](#move-a-document-to-a-folder) afterwards.
</Callout>

## Save Document Blocks

Save the content of a document. The submitted list replaces the document's blocks: existing blocks whose `id` is not in the request are deleted, blocks with a matching `id` are updated, and new ones are created. The array order becomes the block order.

```http
POST /api/public-v1/documents/blocks/store/{uuid}
```

### Path Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `uuid` | string | Yes | Document UUID |

### Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `blocks` | array | Yes | Ordered list of block objects |
| `blocks[].id` | string | Yes | Block UUID (client generated) |
| `blocks[].type` | string | Yes | Block type (for example `paragraph`, `heading`, `table`) |
| `blocks[].props` | object | Yes | Block properties |
| `blocks[].content` | array | No | Block content |
| `blocks[].children` | array | Yes | Nested child blocks (use `[]` when none) |

<Callout type="info" emoji="💡">
  These fields are not checked by a request validator. Omitting `blocks`, or `id`, `type`, `props` or `children` on a block, results in a server error instead of a `422`.
</Callout>

### Example Request

```bash
curl -X POST "https://public-api.taskip.net/api/public-v1/documents/blocks/store/abc123def456" \
  -H "X-Secret-Key: your-secret-key-here" \
  -H "Content-Type: application/json" \
  -d '{
    "blocks": [
      {
        "id": "block-uuid-1",
        "type": "paragraph",
        "props": {},
        "content": [{ "type": "text", "text": "Hello world", "styles": {} }],
        "children": []
      }
    ]
  }'
```

### Example Response

```json
{
  "msg": "document updated",
  "updatedAt": "1 second ago"
}
```

### Errors

- `404` `{"status": 404, "msg": "Document not found"}`
- `422` `{"error": {"msg": ["You don't have permission to update a document"]}}`

## Share a Document with a User

Give a user access to a document, change their access level, or remove their access. Only the document **owner** (the creator) can share it.

```http
POST /api/public-v1/documents/blocks/share/{uuid}
```

### Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `user_id` | integer | Yes | ID of the user |
| `access_type` | integer | Yes (unless removing) | `1` full, `2` edit, `3` view, `4` comment (see [Access Type Values](#access-type-values)). An invalid value returns `422` |
| `action` | string | No | Send `remove` to revoke the user's access |

### Example Request

```bash
curl -X POST "https://public-api.taskip.net/api/public-v1/documents/blocks/share/abc123def456" \
  -H "X-Secret-Key: your-secret-key-here" \
  -H "Content-Type: application/json" \
  -d '{ "user_id": 8, "access_type": 2 }'
```

### Example Responses

```json
{ "status": 200, "msg": "Document Shared Successfully" }
```

```json
{ "status": 200, "msg": "Document Shared Removed" }
```

### Errors

- `404` `{"status": 404, "msg": "Document not found or you are not owner of this document"}`
- `422` `{"status": 422, "msg": "Invalid access type"}` when `access_type` is not a valid access type value
- `422` `{"error": {"msg": ["You don't have permission to share document"]}}`

## Duplicate a Document

Create a copy of a document (name gets a ` copy` suffix) including its blocks. The new document gets its own share row; the original document's sharing/publish state is not changed.

```http
POST /api/public-v1/documents/blocks/duplicate_document/{uuid}
```

No request body is required.

### Example Request

```bash
curl -X POST "https://public-api.taskip.net/api/public-v1/documents/blocks/duplicate_document/abc123def456" \
  -H "X-Secret-Key: your-secret-key-here"
```

### Example Response

```json
{
  "msg": "Document Duplicate successfully",
  "status": 200
}
```

The response does not include the new document's UUID. Call [Get All Documents](#get-all-documents) to find it.

## Download Document as PDF

Generate and return the document as an A4 PDF. Note this is a `POST` request.

```http
POST /api/public-v1/documents/download/{uuid}
```

### Example Request

```bash
curl -X POST "https://public-api.taskip.net/api/public-v1/documents/download/abc123def456" \
  -H "X-Secret-Key: your-secret-key-here" \
  -o document.pdf
```

### JavaScript Example (with Blob)
```javascript
const response = await fetch('https://public-api.taskip.net/api/public-v1/documents/download/abc123def456', {
  method: 'POST',
  headers: { 'X-Secret-Key': 'your-secret-key-here' }
});

if (response.ok) {
  const blob = await response.blob();
  const url = window.URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = 'document.pdf';
  document.body.appendChild(a);
  a.click();
  window.URL.revokeObjectURL(url);
}
```

### Response

The response body is the PDF file (`Content-Type: application/pdf`) rendered from the document's blocks. The file name and PDF title use the document name, followed by the date (`<document name>-<dd-mm-yy>.pdf`).

For an unknown `uuid` the API returns `422` with `{"error": {"msg": ["Document not found"]}}`.

## Invite or Revoke Access

Invite a team member, a client contact or a whole team to a document, change their access level, or revoke access.

```http
POST /api/public-v1/documents-invite/{uuid}
```

### Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `invitationType` | integer | Yes | `1` = Team member, `2` = Contact, `3` = Team |
| `invitationTypeId` | integer | Yes | ID of the team member's user, the contact's user, or the team (depending on `invitationType`) |
| `actionType` | integer | Yes | `0` = invite / update access, `1` = revoke access. Send a JSON integer |
| `access_type` | integer | No | `1` full, `2` edit, `3` view, `4` comment. Not validated; required in practice when inviting |

For contacts (`invitationType: 2`) the contact must have client portal access enabled.

### Example Request

```bash
curl -X POST "https://public-api.taskip.net/api/public-v1/documents-invite/abc123def456" \
  -H "X-Secret-Key: your-secret-key-here" \
  -H "Content-Type: application/json" \
  -d '{
    "invitationType": 1,
    "invitationTypeId": 8,
    "actionType": 0,
    "access_type": 3
  }'
```

### Example Responses

New invitation (a notification is sent to the user, or to each team member):

```json
{
  "msg": "Invitation send successfully",
  "contact": {
    "id": 4,
    "document_id": 126,
    "user_id": 8,
    "access_type": 3,
    "user": {
      "name": "David Chen",
      "image": null,
      "type": "user",
      "email": "david@company.com",
      "contact_id": null
    }
  }
}
```

For `invitationType: 3` the object is returned under `team` instead of `contact`. When the user/team already had access, `msg` is `Access Type Changed successfully`. When revoking, the response is `{"msg": "User access revoke from document"}` (or `{"msg": "Team access revoked from the document"}` for teams).

### Errors

Validation errors return `422` with `{"error": {...}}`. Other `422` errors use `{"error": {"msg": [...]}}`:

- `Document not found`
- `You don't have permission to invite anyone to this document`
- `User not found`
- `This contact does not have portal access and cannot be shared with`

```bash
  -H "X-Secret-Key: your-secret-key-here" \
  -H "Content-Type: application/json" \
  -d '{ "type": 0, "emoji": "📄" }'
```

### Example Response

```json
{
  "data": { "type": 0, "emoji": "📄", "media": null },
  "msg": "Thumbnail Updated"
}
```

For `type` `1`, `media` holds the uploaded file (`id`, `title`, `ext`, `size`, `url`, `media_type`, `createdAt`).

### Errors

- `422` `{"error": {"type": ["The type field is required."]}}` (validation; `emoji` / `media_id` are required for the matching `type`)
- `422` `{"error": {"msg": ["Document not found"]}}`
- `422` `{"error": {"msg": ["You don't have permission to change thumbnail of this document"]}}` (requires an admin or full access)

## Update Cover Photo

Set or replace the document's cover photo.

```http
POST /api/public-v1/documents-cover/{uuid}
```

### Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `type` | integer | Yes | `0` = import from an image URL, `1` = use an already uploaded media file |
| `image_url` | string | Required if `type` is `0` | Image URL to import |
| `media_id` | integer | Required if `type` is `1` | ID of an uploaded media file |

Any existing cover photo is replaced. With `type` `0`, if the image cannot be downloaded from `image_url`, the cover is left unchanged and the response still reports success.

### Example Request

```bash
curl -X POST "https://public-api.taskip.net/api/public-v1/documents-cover/abc123def456" \
  -H "X-Secret-Key: your-secret-key-here" \
  -H "Content-Type: application/json" \
  -d '{ "type": 1, "media_id": 87 }'
```

### Example Response

```json
{
  "data": {
    "id": 87,
    "title": "cover.jpg",
    "ext": "jpg",
    "size": 120345,
    "url": "https://.../cover.jpg",
    "media_type": "image",
    "createdAt": "26-01-2024 02:30:00"
  },
  "msg": "Cover Updated"
}
```

`data` is `null` if no cover photo is set after the call (for example when the `media_id` does not exist).

### Errors

- `422` `{"error": {"type": ["The type field is required."]}}` (validation)
- `422` `{"error": {"msg": ["Document not found"]}}`
- `422` `{"error": {"msg": ["You don't have permission to change cover of this document"]}}` (requires an admin or full access)

## Mention a User

Send a mention notification to a user about a document.

```http
POST /api/public-v1/documents/mention/user
```

### Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | Yes | Name of the mentioned user |
| `document_uuid` | string | Yes | UUID of the document |
| `email` | string | Yes | Email of the mentioned user (must be an existing user in the workspace) |

### Example Request

```bash
curl -X POST "https://public-api.taskip.net/api/public-v1/documents/mention/user" \
  -H "X-Secret-Key: your-secret-key-here" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "David Chen",
    "document_uuid": "abc123def456",
    "email": "david@company.com"
  }'
```

### Example Response

```json
"ok"
```

### Errors

- `422` `{"error": {"email": ["The email field is required."]}}` (validation)
- `422` `{"error": {"msg": ["user not found"]}}` when no user has that email

## Error Responses

| Status Code | Description |
|-------------|-------------|
| `401` | `{"message": "Secret keys are missing."}` - no `X-Secret-Key` header |
| `404` | `{"status": 404, "msg": "Workspace not found"}` - unknown or expired secret key; or `{"status": 404, "msg": "Document not found"}` |
| `422` | Validation errors (`{"error": {"field": ["..."]}}`) and permission/business-rule errors (`{"error": {"msg": ["..."]}}`) |
| `503` | Workspace is in read-only maintenance and the request is a write |
