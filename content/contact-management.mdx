# Contact Management API

The Contact Management API allows you to manage contacts (clients) in your TaskIP CRM system. You can create, read, update, and delete contacts, look a contact up by email, perform bulk deletes, and invite contacts to the client portal.

<Callout type="info" emoji="💡">
  **Resource IDs**: The `{id}` / `{contact}` segment of the contact routes only accepts digits. A non-numeric segment (for example `/contact/foo`) is a `404`.
</Callout>

## Endpoints Overview

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | [`/api/public-v1/contact`](#get-all-contacts) | Get all contacts |
| `POST` | [`/api/public-v1/contact`](#create-a-contact) | Create a new contact |
| `GET` | [`/api/public-v1/contact/{id}`](#get-a-specific-contact) | Get a specific contact |
| `GET` | [`/api/public-v1/contact/find-by-email`](#find-a-contact-by-email) | Find a contact by email address |
| `PUT` / `PATCH` | [`/api/public-v1/contact/{id}`](#update-a-contact) | Update a contact |
| `DELETE` | [`/api/public-v1/contact/{id}`](#delete-a-contact) | Delete a contact |
| `POST` | [`/api/public-v1/contact/bulk-delete`](#bulk-delete-contacts) | Delete multiple contacts |
| `POST` | [`/api/public-v1/contact/invite-client/{id}`](#invite-client) | Invite a contact to the client portal |



### Query Parameters

## Create a Contact

Create a new contact in your system.

```http
POST /api/public-v1/contact
```

<ApiTester
  endpoint="/contact"
  method="POST"
  defaultBody={{
    "first_name": "Alice",
    "last_name": "Johnson",
    "email": "alice.johnson@example.com",
    "phone_number": "555-0125",
    "company_id": 7,
    "country_id": 1,
    "state_id": 5,
    "city_id": 10,
    "address": "123 Business Ave",
    "zip_code": "12345",
    "timezone": "America/New_York",
    "invite_client": true
  }}
  description="Create a new contact with the required information. Modify the request body as needed."
/>

### Request Headers
```http
X-Secret-Key: your-secret-key-here
Content-Type: application/json
```

### Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `first_name` | string | Yes | Contact's first name (max 191 chars). Markup and characters other than letters, spaces, apostrophes, hyphens and dots are stripped |
| `last_name` | string | No | Contact's last name (max 191 chars). Sanitized the same way as `first_name` |
| `email` | string | No | Valid email address. Must not already belong to a user, another contact, or a lead. **Required** when `is_company_contact` is `1`, when `access_portal` is `1`, or when `invite_client` is `true` |
| `phone_code` | string | No | Phone country code (max 5 chars) |
| `phone_number` | string | No | Contact's phone number (max 18 chars) |
| `mobile_phone` | string | No | Mobile number (max 18 chars) |
| `preferred_contact_method_id` | integer | No | ID of an existing preferred contact method |
| `company_id` | integer | No | Associated company ID (must exist) |
| `position` | string | No | Job position/title |
| `country_id` | integer | No | Country ID |
| `state_id` | integer | No | State ID |
| `city_id` | integer | No | City ID |
| `address` | string | No | Contact's address |
| `zip_code` | string | No | ZIP/postal code (max 20 chars) |
| `vat_id` | string | No | VAT ID (max 100 chars) |
| `industry_id` | integer | No | Industry ID |
| `number_of_employees` | integer | No | Number of employees (min 0) |
| `timezone` | string | No | Contact's timezone (max 191 chars) |
| `image` | integer | No | Profile image media ID |
| `access_portal` | integer | No | Portal access (`0` or `1`) |
| `password` | string | Required if `access_portal` = 1 | Password (min 6, max 191 chars) |
| `description` | string | No | Free-text description |
| `tags` | array | No | Array of tags |
| `groups` | array | No | Array of groups |
| `company_members` | array | No | Array of company members |
| `is_company_contact` | boolean | No | Marks the contact as a company contact |
| `custom_fields` | array | No | Custom field data. Required custom fields defined in your workspace are enforced |
| `invite_client` | boolean | No | Send the client portal invitation email (requires `email`) |

<Callout type="info" emoji="💡">
  **Persisted fields**: On create, `first_name`, `last_name`, `email`, `company_id`, `phone_number`, `country_id`, `state_id`, `city_id`, `address`, `zip_code`, `timezone`, `access_portal`, `custom_fields` and `invite_client` are stored. On update, `position` and `image` are stored as well. Other validated fields are currently accepted but not saved by this endpoint.
</Callout>

### Example Request

```bash
curl -X POST "https://public-api.taskip.net/api/public-v1/contact" \
  -H "X-Secret-Key: your-secret-key-here" \
  -H "Content-Type: application/json" \
```

## Update a Contact

Update an existing contact's information.

```http
PUT /api/public-v1/contact/{id}
PATCH /api/public-v1/contact/{id}
```

`PUT` and `PATCH` are handled identically and share the same validation rules as create. Updates are **partial**: fields you omit keep their stored values.

<ApiTester
  endpoint="/contact/1"
  method="PUT"
  defaultBody={{
    "first_name": "Alice",
    "position": "Senior Marketing Director",
    "phone_number": "555-0126"
  }}
  description="Update an existing contact. Replace '1' in the endpoint with the actual contact ID. first_name is always required."
/>

### Path Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `id` | integer | Yes | Contact ID to update (digits only) |

### Request Body
Same fields as [Create a Contact](#create-a-contact). `first_name` is required on every update. Every other field is optional: an omitted field keeps its stored value (only the fields you send are changed). To clear a field, send it explicitly as `null`. The contact's own current email is not treated as a duplicate. A contact that already has portal access cannot have its email removed.

### Example Request

```bash
curl -X PUT "https://public-api.taskip.net/api/public-v1/contact/151" \
  -H "X-Secret-Key: your-secret-key-here" \
  -H "Content-Type: application/json" \
  -d '{
    "first_name": "Alice",
    "last_name": "Johnson",
    "email": "alice.johnson@example.com",
    "position": "Senior Marketing Director",
    "phone_number": "555-0126"
  }'
```

### Python Example
```python
import requests

headers = {
    'X-Secret-Key': 'your-secret-key-here',
    'Content-Type': 'application/json'
}

update_data = {
    "first_name": "Alice",
    "last_name": "Johnson",
    "email": "alice.johnson@example.com",
    "position": "Senior Marketing Director",
    "phone_number": "555-0126"
}

response = requests.put(
    'https://public-api.taskip.net/api/public-v1/contact/151',
    headers=headers,
    json=update_data
)

result = response.json()
```

### Example Response

```json
{
  "msg": "Contact Updated"
}
```

## Error Responses

### Common Error Codes

| Status Code | Error Type | Description |
|-------------|------------|-------------|
| `401` | Unauthorized | Invalid or missing X-Secret-Key |
| `404` | Not Found | Contact not found (show, or a non-numeric ID in the path) |
| `422` | Validation Error | Request data failed validation, or the operation was rejected (for example a duplicate email) |
| `429` | Too Many Requests | Rate limit exceeded, or an invitation was re-sent too soon |

### Example Validation Error Response

Validation failures return `422` with the failing fields under `error`:

```json
{
  "error": {
    "first_name": ["The first name field is required."],
    "email": ["The email field must be a valid email address."]
  }
}
```

Operation errors (for example a plan limit or missing permission) return `422` in this shape. When creating a contact, the workspace's contacts plan limit is checked first, and once it is reached the request is rejected with the plan's limit message:

```json
{
  "error": {
    "msg": ["You do not have permission to add contacts"]
  }
}
```
