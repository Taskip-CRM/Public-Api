# Lead Management API

The Lead Management API allows you to manage leads in your TaskIP CRM system. You can create, read, update, and delete leads, track lead statuses and sources, manage notes and files, and convert leads into contacts.

## Endpoints Overview

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | [`/api/public-v1/lead`](#get-all-leads) | Get all leads |
| `POST` | [`/api/public-v1/lead`](#create-a-lead) | Create a new lead |
| `GET` | [`/api/public-v1/lead/{id}`](#get-a-specific-lead) | Get a specific lead |
| `PUT` / `PATCH` | [`/api/public-v1/lead/{id}`](#update-a-lead) | Update a lead |
| `DELETE` | [`/api/public-v1/lead/{id}`](#delete-a-lead) | Delete a lead |
| `POST` | [`/api/public-v1/lead/bulk-delete`](#bulk-delete-leads) | Delete multiple leads |
| `POST` | [`/api/public-v1/lead/send-email/{lead}`](#send-email-to-a-lead) | Send email to a lead |
| `POST` | [`/api/public-v1/lead/{lead}/convert`](#convert-lead-to-contact) | Convert lead to contact |
| `GET` | [`/api/public-v1/lead/notes/{lead_id}`](#get-lead-notes) | Get all notes for a lead |
| `POST` | [`/api/public-v1/lead/notes/{lead_id}`](#create-a-lead-note) | Create a note for a lead |
| `PUT` | [`/api/public-v1/lead/notes/{lead_id}`](#update-a-lead-note) | Update a lead note |
| `DELETE` | [`/api/public-v1/lead/notes/{lead_id}`](#delete-a-lead-note) | Delete a lead note |
| `GET` | [`/api/public-v1/lead/files/{lead_id}`](#get-lead-files) | Get files for a lead |
| `POST` | [`/api/public-v1/lead/files/{lead_id}`](#upload-lead-files) | Upload files to a lead |
| `DELETE` | [`/api/public-v1/lead/files/bulk-delete/{lead_id}`](#bulk-delete-lead-files) | Bulk delete lead files |
| `GET` | [`/api/public-v1/lead-attribute`](#get-all-lead-attributes) | Get all lead attributes |
| `POST` | [`/api/public-v1/lead-attribute`](#create-a-lead-attribute) | Create a lead attribute |
| `GET` | [`/api/public-v1/lead-attribute/{id}`](#get-a-specific-lead-attribute) | Get a specific lead attribute |
| `PUT` / `PATCH` | [`/api/public-v1/lead-attribute/{id}`](#update-a-lead-attribute) | Update a lead attribute |
| `DELETE` | [`/api/public-v1/lead-attribute/{id}`](#delete-a-lead-attribute) | Delete a lead attribute |

## Get All Leads

Retrieve a paginated list of all leads in your system.

```http
GET /api/public-v1/lead
```

<ApiTester
  endpoint="/lead"
  method="GET"
  description="Retrieve all leads from your TaskIP system. Use query parameters to filter, search, and sort the results."
/>

### Request Headers
```http
X-Secret-Key: your-secret-key-here
Content-Type: application/json
```

### Query Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `search` | string | No | Search by first name, last name, full name, email, or company name |
| `page` | integer | No | Page number for pagination (default: 1) |
| `item` | integer | No | Results per page (default: 10, min 1, max 200) |
| `is_converted` | integer | No | `0` = active leads (default), `1` = converted leads |
| `status_id` | integer | No | Filter by lead attribute status ID |
| `source_id` | integer | No | Filter by lead attribute source ID |
| `assigned_to` | integer | No | Filter by assigned user ID |
| `from_date` | date | No | Only leads with `lead_interaction_date` on or after this date (`Y-m-d`) |
| `to_date` | date | No | Only leads with `lead_interaction_date` on or before this date (`Y-m-d`) |
| `sort_by` | string | No | Sort field: `name`, `lead_interaction_date`, `status` |
| `sort_order` | string | No | Sort direction: `asc` or `desc` (default: `desc`) |

### Example Request

```bash
curl -X GET "https://public-api.taskip.net/api/public-v1/lead?search=john&item=10&is_converted=0" \
  -H "X-Secret-Key: your-secret-key-here" \
  -H "Content-Type: application/json"
```

## Create a Lead

Create a new lead in your system.

```http
POST /api/public-v1/lead
```

<ApiTester

  method="POST"

    "description": "Interested in premium plan",
    "custom_fields": []
  }}
  description="Create a new lead with the required information. Modify the request body as needed."
/>

### Request Headers
```http
X-Secret-Key: your-secret-key-here
Content-Type: application/json
```

### Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `first_name` | string | Yes | Lead's first name (max 191 chars). Markup and characters other than letters, spaces, apostrophes, hyphens and dots are stripped |
| `last_name` | string | No | Lead's last name (max 191 chars) |
| `email` | string | No | Lead's email address. Must not already belong to a user, another lead, or a contact |
| `phone_number` | string | No | Lead's phone number (max 18 chars) |
| `mobile_phone` | string | No | Lead's mobile number (max 18 chars) |
| `job_title` | string | No | Job title (max 191 chars) |
| `preferred_contact_method_id` | integer | No | ID of an existing preferred contact method |
| `website` | string | No | Lead's website, must be a valid URL such as `https://example.com` (max 255 chars) |
| `company_id` | integer | No | Existing company ID |
| `value` | numeric | No | Lead deal value (min 0) |
| `currency` | string | No | Currency code (max 10 chars, e.g. `USD`) |
| `lead_interaction_date` | date | No | Date of interaction (`Y-m-d`) |
| `next_follow_up_date` | date | No | Next follow-up date (`Y-m-d`) |
| `lead_type_id` | integer | No | ID of an existing lead type |
| `assigned_to` | array | No | Array of user IDs to assign (each must exist) |
| `status_ids` | array | No | Array of lead attribute IDs of type status (`type` = 1) |
| `source_ids` | array | No | Array of lead attribute IDs of type source (`type` = 2) |
| `groups` | array | No | Array of existing lead group IDs |
| `tags` | array | No | Array of existing tag IDs |
| `country_id` | integer | No | Country ID |
| `state_id` | integer | No | State ID |
| `city_id` | integer | No | City ID |
| `address` | string | No | Lead's address |
| `zip_code` | string | No | ZIP / postal code (max 8 chars) |
| `description` | string | No | Additional notes or description |
| `custom_fields` | array | No | Array of custom field objects. Required custom fields defined in your workspace are enforced |
| `pipeline_uuid` | string | No | UUID of an existing sales pipeline. Requires `stage_id` |
| `stage_id` | integer | Required with `pipeline_uuid` | ID of a stage in that pipeline. When both are given, a deal for the lead is created in the stage |

## Update a Lead

Update an existing lead's information.

```http
PUT /api/public-v1/lead/{id}
PATCH /api/public-v1/lead/{id}
```

`PUT` and `PATCH` are handled identically.

<ApiTester
  endpoint="/lead/1"
  method="PUT"
  defaultBody={{
    "first_name": "John",
    "phone_number": "555-9999",
    "value": 7500,
    "description": "Follow-up scheduled for next quarter"
  }}
  description="Update an existing lead. Replace '1' in the endpoint with the actual lead ID. first_name is always required."
/>

### Path Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `id` | integer | Yes | Lead ID to update |

### Request Body

Same fields as [Create a Lead](#create-a-lead). `first_name` is required on every update. The lead's fields, assignees, statuses, sources, groups and tags are overwritten with the submitted values, so send the complete set of values you want to keep (an omitted optional field is saved as empty). A lead can keep its own current email. The lead's email is not changed if another user account already uses that email.

### Example Request

```bash
curl -X PUT "https://public-api.taskip.net/api/public-v1/lead/1" \
  -H "X-Secret-Key: your-secret-key-here" \
  -H "Content-Type: application/json" \
  -d '{
    "first_name": "John",
    "phone_number": "555-9999",
    "value": 7500,
    "description": "Follow-up scheduled for next quarter"
  }'
```

### Python Example
```python
import requests

headers = {
    'X-Secret-Key': 'your-secret-key-here',
    'Content-Type': 'application/json'
}

update_data = {
    "first_name": "John",
    "phone_number": "555-9999",
    "value": 7500,
    "description": "Follow-up scheduled for next quarter"
}

response = requests.put(
    'https://public-api.taskip.net/api/public-v1/lead/1',
    headers=headers,
    json=update_data
)

result = response.json()
```

## Bulk Delete Leads

Delete multiple leads at once.

```http
POST /api/public-v1/lead/bulk-delete
```

<ApiTester
  endpoint="/lead/bulk-delete"
  method="POST"
  defaultBody={{
    "ids": [1, 2, 3]
  }}
  description="Delete multiple leads at once. Provide an array of lead IDs to delete. This action cannot be undone."
/>

### Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `ids` | array | Yes | Array of lead IDs to delete (1 to 1000 integers) |

### Example Request

```bash
curl -X POST "https://public-api.taskip.net/api/public-v1/lead/bulk-delete" \
  -H "X-Secret-Key: your-secret-key-here" \
  -H "Content-Type: application/json" \
  -d '{
    "ids": [1, 2, 3]
  }'
```

### Example Response

```json
{
  "msg": "Lead Deleted Successfully"
}
```

If none of the supplied IDs match a lead the API returns `422` with `{"error": {"msg": ["Leads not found."]}}`.

</Callout>

## Error Responses

### Common Error Codes

| Status Code | Error Type | Description |
|-------------|------------|-------------|
| `401` | Unauthorized | Invalid or missing X-Secret-Key |
| `404` | Not Found | Lead or lead attribute not found |
| `422` | Validation Error | Request data failed validation, or the operation was rejected (e.g. lead already converted, lead has no email, mail not connected) |
| `429` | Too Many Requests | Rate limit exceeded |

### Example Error Responses

Validation failures return `422` with the failing fields under `error`:

```json
{
  "error": {
    "first_name": ["The first name field is required."],
    "email": ["This email already exists as a lead. Please use a different email address."]
  }
}
```

Operation errors return `422` in one of these shapes:

```json
{ "error": { "msg": ["Lead already converted to contact."] } }
```

```json
{ "error": "This lead has no email address." }
```
